# Skillrise – HR training platform

Open this folder in VS Code and run `index.html` with Live Server.

| Page | HTML | Extra CSS | JS |
|---|---|---|---|
| Home – Classic | index.html | home1.css | home1.js |
| Home – Premium | premium.html | home2.css | home2.js |
| Programs | programs.html | inner.css | programs.js |
| Program details | program.html?id=p1 | pages.css | program.js |
| Trainers | trainers.html | inner.css | trainers.js |
| Case Studies | case-studies.html | inner.css | case-studies.js |
| About Us | about.html | pages.css | – |
| Blog / Article | blog.html, blog-post.html?id=b1 | pages.css | blog.js, blog-post.js |
| FAQs | faq.html | pages.css | faq.js |
| Contact Us | contact.html | pages.css | contact.js |
| Integration details | integration.html?id=hris | pages.css | integration.js |
| Login / Sign Up | login.html, signup.html | login.css | login.js, signup.js |
| HR Dashboard | dashboard.html | dashboard.css | dashboard.js |

Shared: `css/base.css` (header, footer, colours, buttons), `js/common.js`, `js/data.js` (sample content).
Colours: primary deep teal #0F766E, secondary amber #F59E0B. Light mode is white/light grey, dark mode near-black grey.
Logo: `assets/img/logo.png` (img) and `logo.svg` (favicon).
The login accepts any email and a 4+ character password (demo). The dashboard keeps data in memory only.
